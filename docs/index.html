Feito para construir

Um fluxo claro,
da ideia ao navegador.

GITML combina uma sintaxe de autoria direta com utilitários para desenvolver, validar e gerar páginas web.

⌘

CLI para seu fluxo

Crie projetos, inicie o servidor local, valide arquivos e gere HTML pelo terminal.

▧

Componentes prontos

Use elementos de layout, navegação, formulários e conteúdo com marcação declarativa.

⌘

Ferramentas VS Code

Edite arquivos GITML com recursos de linguagem e comandos da extensão publicada.

◇

HTML semântico

Combine componentes GITML e tags HTML para estruturar suas páginas.

◉

Prévia local

Desenvolva e confira o resultado no navegador enquanto trabalha no projeto.

↗

Saída para publicar

Gere arquivos HTML e leve o resultado para uma hospedagem estática compatível.

Primeiros passos

Instale.
Crie. Experimente.

Instale o pacote pelo npm e consulte o guia do projeto para os comandos e exemplos disponíveis.

Abrir pacote no npm ↗
$ npm install -g gitml
$ gitml new meu-site # cria um projeto
$ cd meu-site
$ gitml dev # inicia a prévia local
